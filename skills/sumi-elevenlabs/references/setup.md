# ElevenLabs first setup · checked 26 October2026

Use the current [API-key guide](https://elevenlabs.io/docs/help-center/technical/how-do-i-authorize-myself-using-an-api-key), [models](https://elevenlabs.io/docs/overview/models), [API pricing](https://elevenlabs.io/pricing/api) and [plans](https://elevenlabs.io/pricing). Recheck before selection; account/voice modifiers and taxes can change the estimate.

1. Explain: online narration uses account allowance/credits and internet; it needs no local speech-model download. Check existing connector/preferences first. Read-only verification is not a paid test. If a user prefers offline/local, offer Voicebox; own recording/no narration remain available.
2. If disconnected, guide the user to Developers→API Keys. Create a named restricted key with only needed speech/list-model/list-voice permissions and an appropriate credit cap. Use a secure connector or masked terminal/OS credential store. Do not ask them to paste the key into chat or expose it in command history. The helper's interactive setup stores macOS credentials in Keychain; elsewhere use the host's secure credential/environment mechanism. An environment variable exists only where configured; do not claim universal persistence.
3. Read saved `preferences`, `check`, `models`, `voices`; use `capabilities` only when plan/clone eligibility matters. Lack of read permission is unknown, not proof a plan lacks cloning. Search/filter returned voices and retain pagination. Let the user choose language/tone and hear existing previews before paying for a take.
4. Explain **characters, not LLM tokens**. Current published base examples for 1,000 characters: v4/v3/Multilingual v2 about US$0.08; v4 Turbo/Flash-Turbo about US$0.04. A 500-character script is about US$0.04 or US$0.02 before tax/modifiers. Included allowance may cover usage; check actual account credit conversion rather than promising universal rates. Multilingual v2 suits stable narration when language fits, expressive models suit drama, Flash/Turbo can reduce cost. Verify returned modelID and the actual supported endpoint; do not pass a model into an incompatible helper.
5. Recommend optional personal/consented voice recording for identity; a licensed stock voice is fine. Current plans list InstantCloning onStarter and ProfessionalCloning onCreator, but access/voice eligibility must be checked. A key alone does not grant access. Never bypass a rejected clone or silently replace it. Do not promise monetization from a voice choice; original production and platform/voice rights matter.
6. Ask whether to remember the selected voice/model or use it for this film only. `set-default-voice` verifies returned IDs; project-only casts preserve defaults. Store non-secret settings only. Supplied recordings, API receipts and takes stay outside the public package.
7. Before generation show exact text, character count, voice/model, projected cost/budget and approval. Submit once, retain raw audio/alignment/requestID and measure its real length. Inspect uncertain output instead of automatically retrying. Check missing words, pronunciation and emotional delivery; sync the film/captions to the actual full take.

Helper discovery: `python3 scripts/elevenlabs_voice.py --help`. It is an optional stdlib adapter, not a universal MCP server and not a guarantee of credentials/model access on every host. It uses verified compatible TTS endpoints; for another endpoint use a documented connector/adapter. No paid generation is needed merely to install this skill.

## Spoken language is model-specific

The assistant may write the story in more languages than a particular speech model supports. Check the selected model's current language list before generation. As checked on 26 October 2026, ElevenLabs documents 90+ languages for v4/v4 Turbo, 70+ for v3, 29 for Multilingual v2 and 32 for Flash v2.5. Broad “80+” narration copy can refer to an eligible model, not every model or voice route. [Official model capabilities](https://elevenlabs.io/docs/overview/models/). No pricing was researched for this clarification.
