# Narration

Offer in this order, reuse a saved choice after checking it still works, and load only the chosen guide.

1. **Voicebox:** free and local. Use the [Voicebox companion](../../sumi-voicebox/SKILL.md). It owns requirements, model downloads and language checks. Confirm the language first; its setup guide lists no Urdu engine.
2. **ElevenLabs:** paid. Use the [ElevenLabs companion](../../sumi-elevenlabs/SKILL.md). It owns credentials, voices and cost. Approve each take, because a connected key is not permission to spend.
3. **No narration:** no voice tools, keys or invented speech. Captions, music and effects carry the story. See [Sound](../../sumi-sound/SKILL.md).

If the user offers their own recording, follow [supplied narration](supplied-narration.md). Keep the original untouched, and build the timing around the real performance.

The story's language comes from the assistant. Whether it can be spoken depends on the voice model, so confirm the language and script before promising it.

Keep narrator lines off character mouths. Save only the route, voice or model the user asks to remember, outside this package, as described in [memory](memory.md).
