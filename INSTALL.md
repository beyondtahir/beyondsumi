# Install Beyondsumi

## Codex or Claude Code: install as a plugin

**Codex:**

```sh
codex plugin marketplace add beyondtahir/beyondsumi
codex plugin add beyondsumi@beyondsumi
```

**Claude Code:**

```text
/plugin marketplace add beyondtahir/beyondsumi
/plugin install beyondsumi@beyondsumi
```

Then open a new chat and say "Use Beyondsumi". It welcomes you, shows the six steps and checks your computer.

## The easy way: let your assistant do it

1. Download the Beyondsumi ZIP and double-click it to unpack it.
2. Open your assistant, such as Codex or Claude Code.
3. Copy this message, put the folder's location where it says FOLDER, and send it. On a Mac, you can drag the folder into the chat.

> Please install Beyondsumi for me from FOLDER. Read INSTALL.md in that folder, choose the guide for this app and do the steps yourself. I am a complete beginner, so tell me in simple words what is happening. If it needs my permission or a missing program, explain why and ask me first. When it is done, start the Beyondsumi first-time helper.

If your assistant asks for permission to copy the files, say yes. It will then welcome you and check what your computer can do.
